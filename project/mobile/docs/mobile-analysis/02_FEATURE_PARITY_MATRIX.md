# 02 — Complete Web-to-Mobile Feature Parity Matrix

> **Status Definitions (Mandatory):**
> - **Implemented and Connected:** Full UI + live backend API + DB persistence working end-to-end.
> - **Implemented but Incomplete:** Connected to backend or storage, but contains confirmed bugs, missing fields, stubbed sub-widgets, or local-only sub-features.
> - **UI Only:** Visual markup, inert controls, or browser `localStorage`-only without backend backing.
> - **Coming Soon:** Explicitly rendered by `/dashboard/settings/[...slug]` placeholder.
> - **Not Implemented:** Referenced in schema/roadmap/seeded entitlements, not implemented in runtime flows.
> - **Cannot Verify:** External runtime behaviors (e.g., live Stripe webhooks or Ollama GPU cold-start) not executed live during static audit.
